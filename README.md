# AI-Attendent-System

Smart Face AI Attendance Verification System with Local SQLite Database, Real-Time Face Biometrics (128-D), Session Management, and Exportable Reports.

## ✨ Features
- **Live AI Face Recognition**: High accuracy real-time facial recognition using SSD MobileNet & Tiny Face Detector.
- **Smart Voice Feedback**: Automatic name pronunciation (Khmer & English) upon check-in.
- **Session Management**: Full CRUD for sessions with course, major, lecturer, room, class & batch.
- **Student Registration**: Face capture and 128-D vector embedding stored in SQLite.
- **Attendance Analytics & Reports**: Live dashboard metrics and export to Excel (.xlsx) / CSV.
- **Mobile Responsive**: Sleek dark mode UI tailored for desktop and mobile devices.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Full-Stack Application
```bash
node start-all.js
```
- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:5000`
